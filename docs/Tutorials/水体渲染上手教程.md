# 水体渲染器上手教程

面向第一次阅读本仓库的人，帮助快速理解 **从启动到渲染出一帧水面** 的完整流程。
渲染思路基于 Tessendorf 海洋波模型 + FFT，使用 C++17 与 Vulkan。

---

## 0. 一句话总览

CPU 用 **Tessendorf 波谱 + FFTW 逆变换** 每帧算出两张纹理（位移图、法线图），
上传到 GPU；顶点着色器用位移图把平面网格"顶起来"成波浪，
片元着色器用法线图 + 几何光学（Fresnel/折射/水下衰减）算出水面颜色。

```
波谱(Phillips) --IFFT--> 位移图+法线图 --上传GPU--> 顶点位移 --> 片元光照 --> 屏幕
     (CPU, WSTessendorf)        (Texture2D)      (.vert)        (.frag)
```

## 2. 启动流程（按调用顺序）

1. **`main.cpp:16`** — 初始化日志，构造 `WaterSurface`，调用 `app.Run()`。
2. **`Application::Run`** → `SetupWindow()` + `SetupVulkan()` → **`Start()`**（`Application.cpp:44`）。
3. **`WaterSurface::Start()`**（`WaterSurface.cpp:36`）：
   - `CreateRenderPass()` 建渲染通道
   - 建绘制命令池 / 命令缓冲 / 描述符池
   - `SetupAssets()` → 建 GUI、相机、**水面网格**、天空
4. **`CreateWaterSurfaceMesh()`**（`WaterSurface.cpp:62`）：
   - `new WaterSurfaceMesh(...)` 构造，里面顺序做：
     描述符布局 → 管线 → staging buffer → **Tessendorf 模型** → **网格**
     （`WaterSurfaceMesh.cpp:26`）
   - `CreateRenderData()` 建管线/UBO/描述符集
   - `Prepare(cmdBuffer)` 做一次性初始化（见第 3 节）
5. 进入 **主循环 `Application::Loop()`**（`Application.cpp:51`），每帧：
   `glfwPollEvents` → `Update(dt)` → 取交换链图像 → `Render()` → 提交 → 呈现。

> 编译运行（README 推荐流程）：
> ```
> mkdir build && cd build
> cmake ..
> make
> ./water
> ```
> 依赖：C++17、CMake、Vulkan SDK；库 GLFW3/SPDLOG/GLM/ImGui/STB/Shaderc/FFTW 在 `libs/`。

## 3. 一次性准备（Prepare）

`WaterSurfaceMesh::Prepare`（`WaterSurfaceMesh.cpp:77`）：

1. `CreateFrameMaps` — 为每个分辨率(16~1024)预建一对纹理（位移图+法线图），
   格式 `R32G32B32A32_SFLOAT`（`WaterSurfaceMesh.cpp:596`）。
2. `PrepareModelTess`（`:123`）：
   - `m_ModelTess->Prepare()` — 波谱预计算（见第 4 节）。
   - 跑一次 `ComputeWaves(0)` 初始化纹理数据并上传。
3. `PrepareMesh`（`:90`）：
   - `CreateGridVertices`（`:500`）生成 `(N+1)×(N+1)` 顶点的平面网格，
     顶点带位置(y=0)和 UV。
   - `CreateGridIndices`（`:538`）生成三角形索引。
   - 上传顶点/索引缓冲。

## 4. 波谱与 FFT（数据的源头，纯 CPU）

文件：**`src/scene/WSTessendorf.cpp`**，用 **FFTW** 库（`<fftw3.h>`）。

### 4.1 预计算 `Prepare()`（`:36`）
- `ComputeWaveVectors()`（`:60`）— 离散波矢量 k。
- `ComputeGaussRandomArray()`（`:87`）— 高斯随机数。
- `ComputeBaseWaveHeightField()`（`:105`）— 用 **Phillips 谱**（`WSTessendorf.h:249`）
  算出每个波矢量的基础复振幅 h0 及其共轭、色散频率（OpenMP 并行）。
- `SetupFFTW()`（`:150`）— 分配复数缓冲并创建 7 个（开启雅可比则 9 个）
  `fftwf_plan_dft_2d`，方向 `FFTW_BACKWARD`（频域→空间域）。

### 4.2 每帧 `ComputeWaves(t)`（`:284`）
1. 由 `h0` 和时间 t 算当前频域高度场 `WaveHeightFT`（`WSTessendorf.h:265`）。
2. 由高度场乘 `i·k` 得到斜率、位移的频域表示。
3. **执行 IFFT**：`fftwf_execute(...)`，用 OpenMP `#pragma omp sections` 并行
   （`WSTessendorf.cpp:342-378`）。
4. 把结果整理进：
   - `m_Displacements` = `vec4(位移X, 高度, 位移Z, jacobian)`
   - `m_Normals`       = `vec4(slopeX, slopeZ, dDxdx, dDzdz)`
   - `NormalizeHeights`（`:443`）把高度归一化到 [-1,1]，返回振幅供着色器还原。

> 注意：FFT 全在 **CPU** 完成，GPU 没有 compute-shader FFT。

## 5. 每帧更新与上传（CPU→GPU）

`WaterSurface::Update`（`WaterSurface.cpp:134`）→ `WaterSurfaceMesh::Update`（`:145`）：
- 推进时间 `m_TimeCtr`，调 `ComputeWaves` 重算波形。
- `CopyModelTessDataToStagingBuffer` 把位移/法线数组拷进 staging buffer。

`WaterSurface::Render`（`:144`）里先 `PrepareRender`（`WaterSurfaceMesh.cpp:156`）：
- 填 `VertexUBO`（model/view/proj、高度振幅、choppy、纹理 scale）。
- 填 `WaterSurfaceUBO`（相机位置、水体吸收/散射系数、地形色、天空参数）。
- `UpdateUniformBuffer` + `UpdateDescriptorSet` 更新描述符。
- `UpdateFrameMaps`（`:642`）把 staging buffer 拷进两张 GPU 纹理。

## 6. GPU 着色

### 6.1 顶点着色器 `WaterSurfaceMesh.vert`
- 采样 **位移图** → 把平面顶点 `inPos` 偏移成波浪 `outPos = inPos + D.xyz`。
- 采样 **法线图** 的斜率 → 算世界法线（含 choppy 校正）。
- 输出裁剪空间位置与法线、UV 给片元。

### 6.2 片元着色器 `WaterSurfaceMesh.frag`
水面视为局部平面，按几何光学合成颜色：
```
L = F_r·L_s + F_r·L_a + F_t·L_u
```
- `F_r`/`F_t` Fresnel 反射/透射率（空气↔水，IOR 1.0/1.33477）。
- `L_s` 太阳直射反射、`L_a` Preetham 天空光（`SkyLuminance`）。
- 折射射线打到水下深度 `height` 处的假想地面，采样地形色后
  按吸收/散射系数衰减得 `L_u`。

### 6.3 绘制顺序（`WaterSurface.cpp:183`）
先画天空（不写深度）→ 画水面网格 → 画 ImGui。

## 7. 关于 LOD / 四叉树（重要澄清）

- **没有几何 LOD，没有四叉树，没有曲面细分着色器。**
- 全代码无 quadtree / tessellation control&eval shader；
  仅有的 `mipLodBias/minLod/maxLod` 是纹理 mipmap（`Texture2D.cpp`），与几何无关，
  且默认 `s_kUseMipMapping=false` 关闭。
- 水面是 **单块等密度方形网格**，分辨率由 GUI 手动选(16~1024)，不随距离自适应：
  - `Patch Resolution`（波谱分辨率）`WaterSurfaceMesh.cpp:812`
  - `Grid Resolution`（网格几何分辨率）`WaterSurfaceMesh.cpp:915`
- README 的 TODO 中 "LOD / Endless / 四叉树解决 tiling" 均**尚未实现**。

## 8. 调试与上手建议

- **看波形数据**：在 `WSTessendorf::ComputeWaves` 打断点，观察 `m_Displacements`。
- **看几何**：app 开启了 `fillModeNonSolid`，可改管线为线框模式看网格密度。
- **调参数**：运行后按 `ESC` 切换 GUI，调风速/风向/Phillips 振幅/分辨率，点 `Apply`。
- **改起点小**：先把分辨率调到 16 跑通流程，再加大。
- **改 FFT**：若想移植到 GPU compute，入口在 `WSTessendorf.cpp` 的 `ComputeWaves`。
